I was using my previous packages noviceDeveloperResources and noviceDeveloperResources2 to automatically load a list of packages, when I encountered an obscure error message. I eventually tracked down the error, which arose from several recursive dependencies not being installed in my library.

I developed the current package InstallationDriver to avoid this problem for myself and other users in the future. It recursively finds any missing CRAN package dependencies (“Depends”, “Imports”, “LinkingTo”) and installs them from the CRAN repository. The main mechanisms used are tools::package_dependencies() and utils::install.packages().
